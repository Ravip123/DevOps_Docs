Linux Commands for DevOps & Production Ops

A working reference for day-to-day production operations: diagnosing incidents, managing networking, disks, users/permissions, services, and routine cleanup — with the flags that actually matter under pressure.

RHEL / Ubuntu / Debian compatible
systemd-based
requires sudo/root where noted
01

Troubleshooting

CPU, memory, load, I/O and process-level diagnostics — the first commands to run when something's on fire.

System Load & Resource Usage

safe / read-only
top
Live process view — CPU, memory, load average.
htop
Interactive, color version of top (install separately).
uptime
System uptime and 1/5/15-minute load averages.
vmstat 2 5
Memory, swap, I/O, CPU stats every 2s, 5 samples.
mpstat -P ALL 2
Per-core CPU utilization (part of sysstat).
free -h
Human-readable RAM and swap usage.
nproc
Number of available CPU cores.
sar -u 1 5
Historical/live CPU utilization report.

Process Diagnostics

safe / read-only
ps aux --sort=-%cpu | head -15
Top 15 processes by CPU usage.
ps aux --sort=-%mem | head -15
Top 15 processes by memory usage.
pstree -p
Process tree with PIDs, shows parent/child relations.
strace -p <PID>
Trace syscalls of a running process (great for hangs).
ltrace -p <PID>
Trace library calls of a running process.
lsof -p <PID>
List open files/sockets held by a process.
cat /proc/<PID>/status
Detailed process state, memory, threads from procfs.
kill -l
List all available signals.
kill -15 <PID>
Graceful terminate (SIGTERM) — try this before -9.
kill -9 <PID>
Force kill (SIGKILL) — last resort, no cleanup.

I/O & Disk Latency

safe / read-only
iostat -xz 2 5
Per-device I/O stats: %util, await, r/s, w/s.
iotop -o
Live view of processes doing disk I/O (root required).
dstat -cdngy
Combined CPU/disk/net/paging view, one line per interval.

System Info & Boot History

safe / read-only
uname -a
Kernel version, architecture, hostname.
hostnamectl
Hostname, OS, kernel, virtualization details.
dmesg -T | tail -50
Kernel ring buffer with human timestamps — hardware/driver errors.
last -x | head -20
Login history plus shutdown/reboot events.
who -b
Last system boot time.
journalctl -k -b
Kernel log for the current boot.
TIP
When load average is high but CPU% looks fine, check vmstat's b column (processes blocked on I/O) and iostat's await — it's usually disk or network wait, not compute.
02

Networking

Interfaces, connectivity checks, ports/sockets, DNS, routing, and firewall rules.

Interfaces & Addresses

safe / read-only
ip a
List interfaces and assigned IP addresses (replaces ifconfig).
ip link show
Interface link state (UP/DOWN), MTU, MAC address.
ip route
Kernel routing table / default gateway.
ip neigh
ARP/neighbor table.
ethtool eth0
NIC link speed, duplex, driver info.
nmcli device status
NetworkManager device/connection status.

Connectivity & Latency

safe / read-only
ping -c 4 <host>
Basic reachability + round-trip latency.
traceroute <host>
Hop-by-hop path to a destination.
mtr <host>
Continuous traceroute + ping — great for intermittent loss.
curl -Iv https://host
HTTP headers + verbose TLS/connection handshake info.
curl -w "%{time_total}\n" -o /dev/null -s https://host
Measure total request time only.
nc -zv <host> <port>
Check if a specific TCP port is open/reachable.
telnet <host> <port>
Manual TCP port test (legacy but still handy).

Ports, Sockets & Connections

safe / read-only
ss -tulpn
Listening TCP/UDP ports with owning process (replaces netstat).
ss -tan state established
All established TCP connections.
ss -s
Socket usage summary statistics.
lsof -i :<port>
Which process is bound to a given port.
netstat -tulpn
Legacy equivalent of ss -tulpn where installed.

DNS

safe / read-only
dig example.com
Full DNS resolution details (authoritative, TTL, etc).
dig +short example.com
Just the resolved IP(s).
nslookup example.com
Quick lookup / reverse lookup.
host example.com
Simple forward/reverse DNS lookup.
cat /etc/resolv.conf
Configured DNS resolvers.
systemd-resolve --status
systemd-resolved status per interface.

Firewall

requires root
sudo iptables -L -n -v
List active iptables rules with packet counters.
sudo firewall-cmd --list-all
firewalld: active zone, services, ports (RHEL/CentOS).
sudo firewall-cmd --add-port=8080/tcp --permanent && sudo firewall-cmd --reload
Open a port permanently and reload.
sudo ufw status verbose
UFW status and rules (Ubuntu/Debian).
sudo ufw allow 443/tcp
Allow a port through UFW.
$ ss -tulpn | grep :443 # confirm nginx/haproxy is actually listening $ curl -Iv https://internal-service:443 # check TLS handshake + headers $ dig +short api.internal.svc # confirm DNS resolves inside the VPC $ mtr api.internal.svc # isolate packet loss vs a specific hop
03

Disk Management

Usage, partitions, filesystems, mounting, and LVM operations.

Usage & Inventory

safe / read-only
df -hT
Disk space per filesystem, with type, human-readable.
df -i
Inode usage — a full inode table blocks writes even with free space.
du -sh /var/log/*
Size of each item in a directory, summarized.
du -h --max-depth=1 / | sort -rh | head -20
Largest top-level directories — classic "what's eating my disk" command.
lsblk -f
Block devices, partitions, filesystem types, mountpoints, UUIDs.
blkid
UUID and filesystem type per block device.
fdisk -l
List disks and partition tables (root recommended).

Mounting & Filesystems

requires root
mount /dev/sdb1 /mnt/data
Mount a device at a mountpoint.
umount /mnt/data
Unmount cleanly (fails if in use — see lsof/fuser).
fuser -mv /mnt/data
Find processes holding a mountpoint busy.
mount -a
Mount everything listed in /etc/fstab.
mkfs.ext4 /dev/sdb1
Format a partition as ext4. Destructive — verify device first.
tune2fs -l /dev/sdb1
Show ext filesystem parameters.
fsck -f /dev/sdb1
Filesystem check/repair — unmount the device first.
resize2fs /dev/sdb1
Grow/shrink an ext filesystem after resizing the underlying partition.

LVM (Logical Volume Manager)

requires root
pvs / pvdisplay
List physical volumes.
vgs / vgdisplay
List volume groups and free space.
lvs / lvdisplay
List logical volumes.
lvextend -L +10G /dev/vg0/lv_data
Grow a logical volume by 10GB.
resize2fs /dev/vg0/lv_data
Expand ext filesystem to match the extended LV.
xfs_growfs /mnt/data
Expand an XFS filesystem (mounted, no unmount needed).
CAUTION
mkfs, fdisk/parted writes, and dd to a block device are destructive and irreversible. Always confirm the exact device path with lsblk before running them in production.
04

Users & Permissions

Account creation, group management, sudo, and file permission controls.

User Creation & Management

requires root
useradd -m -s /bin/bash -c "Jane Doe" jdoe
Create a user with a home dir, default shell, and comment/full name.
passwd jdoe
Set/reset the user's password interactively.
usermod -aG docker,sudo jdoe
Append user to secondary groups (-a is critical — omitting it replaces all groups).
usermod -L jdoe
Lock an account (disable password login).
usermod -s /usr/sbin/nologin jdoe
Disable interactive shell access without deleting the account.
userdel -r jdoe
Delete a user and their home directory/mail spool.
chage -l jdoe
View password expiry / aging policy for a user.
id jdoe
Show UID, GID, and group memberships.
getent passwd jdoe
Look up a user across local files/LDAP/NIS sources.

Group Management

requires root
groupadd deploy
Create a new group.
gpasswd -a jdoe deploy
Add a user to an existing group.
gpasswd -d jdoe deploy
Remove a user from a group.
groups jdoe
List all groups a user belongs to.

Sudo & Privilege Escalation

requires root
visudo
Safely edit /etc/sudoers with syntax validation on save.
visudo -f /etc/sudoers.d/jdoe
Add a scoped sudo rule in a drop-in file (preferred over editing sudoers directly).
sudo -l -U jdoe
List what a specific user is permitted to run via sudo.
sudo -u appuser whoami
Run a command as a different user.

File Permissions & Ownership

requires appropriate rights
chmod 750 /opt/app/deploy.sh
rwx for owner, r-x for group, none for others.
chmod -R g+w /var/www/shared
Recursively add group write access.
chown appuser:appgroup /opt/app -R
Recursively change owner and group of a directory tree.
chmod u+s /usr/local/bin/tool
Set the SUID bit — runs as file owner regardless of caller (use sparingly).
chmod g+s /srv/shared
SGID on a directory — new files inherit the parent group.
chmod +t /srv/shared
Sticky bit — only file owners can delete their own files in a shared dir.
umask 027
Set default permission mask for newly created files in this shell.
getfacl /opt/app
View extended ACLs beyond standard owner/group/other.
setfacl -m u:jdoe:rwx /opt/app
Grant a specific user rwx via ACL without changing ownership.
TIP
Prefer usermod -aG and per-user files in /etc/sudoers.d/ over editing /etc/sudoers or replacing group lists directly — both are easy ways to accidentally lock yourself, or worse, root, out.
05

Services & Processes

systemd service lifecycle and dependency inspection.

systemd Service Control

requires root for write ops
systemctl status nginx
Current state, recent logs, and PID of a service.
systemctl start|stop|restart nginx
Control service lifecycle.
systemctl reload nginx
Reload config without dropping connections (where supported).
systemctl enable --now nginx
Enable on boot and start immediately in one command.
systemctl daemon-reload
Reload unit files after editing a .service file.
systemctl list-units --type=service --state=running
List all currently running services.
systemctl list-units --state=failed
Show all failed units — good first check after an incident.
systemctl is-enabled nginx
Check whether a service is set to start on boot.
systemd-analyze blame
Which units took longest during boot.
06

Cleanup

Reclaiming disk space safely: logs, packages, caches, containers, and temp files.

Logs & journald

requires root
journalctl --disk-usage
Check how much disk journald logs are consuming.
journalctl --vacuum-time=7d
Delete journal entries older than 7 days.
journalctl --vacuum-size=500M
Cap total journal size to 500MB.
find /var/log -name "*.log" -mtime +30 -delete
Delete plain log files older than 30 days.
find /var/log -name "*.gz" -mtime +90 -delete
Remove old compressed/rotated logs.
logrotate -f /etc/logrotate.conf
Force log rotation immediately instead of waiting for the cron schedule.

Package Manager Caches

requires root
apt clean && apt autoremove -y
Debian/Ubuntu — clear downloaded .deb cache, remove orphaned packages.
dnf clean all
RHEL/Fedora — clear yum/dnf metadata and package cache.
yum autoremove -y
Remove packages installed as dependencies that are no longer needed.

Docker / Containers

requires root or docker group
docker system df
Disk usage breakdown by images, containers, volumes, cache.
docker system prune -af --volumes
Remove all unused containers, networks, images, and volumes. Destructive.
docker image prune -a
Remove all images not referenced by any container.
docker container prune
Remove all stopped containers.
docker volume prune
Remove unused (dangling) volumes.

Temp Files & General Sweep

requires root
find /tmp -type f -atime +7 -delete
Remove files in /tmp not accessed in 7 days.
find / -xdev -type f -size +500M -exec ls -lh {} \;
Locate files over 500MB on the root filesystem (won't cross mounts).
find / -type f -name "core" -mtime +7 -delete
Clean up old core dump files.
> /var/log/huge-app.log
Truncate a log file in place without deleting it (keeps the file handle valid for the running process).
CAUTION
Never rm a log file that's still open by a running process if the app expects to keep writing to that path — truncate with > file.log instead, or the disk space won't actually be released until the process is restarted anyway (deleted-but-open files still hold space).
07

Logs & Auditing

Reading and filtering logs quickly during an incident.

Reading Logs

safe / read-only
journalctl -u nginx -f
Follow live logs for a specific systemd unit.
journalctl -u nginx --since "10 min ago"
Logs for a unit within a relative time window.
journalctl -p err -b
Error-level and above messages since last boot.
tail -f /var/log/syslog
Follow a flat-file log in real time.
grep -i "error\|fail" /var/log/app.log | tail -50
Filter recent error/failure lines from an app log.
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head
Top requesting IPs from an access log.
zgrep "500" access.log.*.gz
Search inside gzip-compressed rotated logs.

Auditing Access

requires root
last -a
Recent login sessions with source host.
lastb
Recent failed login attempts.
ausearch -m USER_LOGIN
Search audit logs for login events (requires auditd).
w
Currently logged-in users and what they're running.
history | tail -50
Recent shell command history for the current user.
08

Emergency One-Liners

Copy-paste sequences for the most common production fires.

Disk is full

$ df -hT # which filesystem is full $ du -h --max-depth=1 / 2>/dev/null | sort -rh | head -15 $ find / -xdev -type f -size +200M -exec du -h {} \; 2>/dev/null | sort -rh | head $ journalctl --vacuum-size=200M $ docker system prune -af --volumes # if applicable

Server unresponsive / high load

$ uptime $ top -bn1 | head -20 $ vmstat 1 5 $ ps aux --sort=-%cpu | head -10 $ dmesg -T | tail -30 # rule out OOM killer / hardware

Service won't start

$ systemctl status myapp $ journalctl -u myapp -n 100 --no-pager $ journalctl -u myapp -p err -b $ ss -tulpn | grep <port> # port already bound? $ systemctl daemon-reload && systemctl restart myapp

Can't reach a downstream host

$ ping -c 4 <host> $ dig +short <host> $ mtr <host> $ nc -zv <host> <port> $ sudo iptables -L -n -v | grep <port> # local firewall blocking egress?
TIP
In any incident, capture uptime, free -h, df -hT, and journalctl -p err -b output first, before making changes — it's the cheapest possible snapshot and pays off during the postmortem.
