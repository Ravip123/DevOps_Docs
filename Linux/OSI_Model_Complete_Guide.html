Encapsulation

Application(Data) ↓ Transport (+TCP Header)=Segment ↓ Network (+IP Header)=Packet ↓ Data Link (+MAC Header/Trailer)=Frame ↓ Physical = Bits

Decapsulation

Bits → Frame → Packet → Segment → Data

Real Example

  1. Type https://google.com
  2. DNS resolves IP.
  3. TCP 3-way handshake.
  4. TLS encryption.
  5. HTTP request sent.
  6. Routers forward packets.
  7. Server responds.
  8. Browser renders page.

TCP/IP Mapping

  • Application = OSI 5-7
  • Transport = OSI 4
  • Internet = OSI 3
  • Network Access = OSI 1-2
